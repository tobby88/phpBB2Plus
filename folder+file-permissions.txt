phpBB2 Plus writable folders and files
======================================

Git does not store arbitrary Unix permissions or directory permissions. Run
`set-permissions.sh` after extracting or deploying the board instead.

The paths below are relative to the phpBB2 web root.

Writable folders
----------------

Recommended mode: 0775 when PHP runs as the owner or in the owning group.

/album_mod/upload
/album_mod/upload/cache
/cache
/cgi-bin/tmp
/games
/files
/files/thumbs
/images/avatars
/logs
/pafiledb/cache
/pafiledb/cache/templates
/pafiledb/images/screenshots
/pafiledb/uploads

Executable CGI files
--------------------

Recommended mode: 0755.

/cgi-bin/nuffload.cgi

The Nuffload CGI uploader is optional. It also requires a server with Perl CGI
support and the Perl CGI module; leave `perl_uploader` disabled otherwise.

Shared-hosting fallback
-----------------------

If PHP cannot write with the recommended modes because it runs as a different
user and group, the historical modes can be applied explicitly:

    PHPBB_WRITABLE_DIR_MODE=0777 PHPBB_WRITABLE_FILE_MODE=0666 \
        ./set-permissions.sh /path/to/phpbb/webroot

World-writable permissions should only be used when the hosting setup requires
them. The script defaults to 0775 for folders and 0664 for files.
