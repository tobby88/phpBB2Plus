# phpBB3 conversion coverage

The source for this conversion is the current UTF-8 Plus distribution in `phpBB2/`. The installer in the assembled web root offers **phpBB2 Plus (UTF-8)** as a separate converter. Always use a new destination database and an offline copy of both the source database and its media. Keep that copy intact until counts, permissions, representative files and application behaviour have been checked.

Writing to source member 1 selects that member’s remapped native account. If the original saved folder is gone, its bookmark opens the native mailbox. Earlier preview conversions need the original source to identify individual saved messages reliably. |

Active Plus extensions use the installed package names, versions and authors. A separate paginated section reproduces the old board’s visible credits and links. Hidden rows and source metadata survive conversion. A separately permissioned ACP under **General → Board configuration** can add, edit, publish, hide and remove historical credits. |
