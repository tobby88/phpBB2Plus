# phpBB3 conversion coverage

The source for this conversion is the current UTF-8 Plus distribution in `phpBB2/`. The installer in the assembled web root offers **phpBB2 Plus (UTF-8)** as a separate converter. Always use a new destination database and an offline copy of both the source database and its media. Keep that copy intact until counts, permissions, representative files and application behaviour have been checked.

## Restore a custom smiley on an earlier phpBB3 preview

If the image was imported but its code appears as plain text in a converted post, rebuild that post with phpBB’s text reparser. Run the following from the assembled board directory, replacing `123` in both options with the affected post ID.

```sh
php bin/phpbbcli.php reparser:reparse post_text --range-min=123 --range-max=123 --dry-run
```

Repeat the command without `--dry-run` to save the repaired formatting. In the tested post, the editor text, edit history and formatting options were preserved.
